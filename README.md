# Nexus School Management System

A simple school management system created as a second-year Computer Science project.

The application is a fictional school administration tool. It runs in the browser from `index.html` and can be hosted on GitHub Pages. No server or database is used.

## Features

- Demo login
- Dashboard statistics
- Student management
- Teacher management
- Class management
- Attendance tracking
- Marks management
- Search
- Filtering
- CRUD operations
- LocalStorage
- Responsive design

## Technologies

- HTML5
- CSS3
- JavaScript

## Concepts Used

- Variables
- Functions
- Arrays
- Objects
- DOM manipulation
- Event listeners
- Form validation
- CRUD
- LocalStorage
- Responsive CSS

## How to Run

1. Download or clone the folder.
2. Open `index.html` in a web browser.

To put it on GitHub Pages, upload these files and set GitHub Pages to use the main branch root.

## Limitations

This is an educational front-end project.
It does not contain:

- a real backend
- a real database
- real authentication
- real student information

All student, teacher and academic information is fictional.
